\subsubsection{\texttt{summarise()} --- grouped summaries}
\ixch{summarise()}%
\ixc{summarise()} is most useful with \ixc{group\_by()} (one summary per group). Without grouping:
\begin{rcode}
mpg %>%
  summarise(avg_hwy = mean(hwy)) (*@\ixch{summarise()}\ixch{mean()}@*)
\end{rcode}
\begin{routput}
  avg_hwy
1    23.4
\end{routput}
= average over \emph{all cars}; not very useful. By class / manufacturer, with \ixc{arrange()}:
\begin{rcode}
mpg %>%
  group_by(class) %>% (*@\ixch{group\_by()}@*)
  summarise(avg_hwy = mean(hwy)) %>%
  arrange(avg_hwy) (*@\ixch{arrange()}@*)
# same with group_by(manufacturer)
\end{rcode}
\begin{routput}
